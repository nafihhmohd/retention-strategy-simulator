# retention-strategy-simulator
End-to-end prescriptive analytics on UCI Online Retail II. Predicts customer churn via Logistic Regression, estimates 6-month CLV using BG/NBD + Gamma-Gamma models, quantifies revenue at risk, and simulates Discount / Loyalty / Engagement retention strategies with ROI comparison. Built with Python, Scikit-learn, Lifetimes &amp; Streamlit.
